     1→/**
     2→ * Shared contract between the Next.js frontend and the chat-service
     3→ * mini service (socket.io, port 3003). DO NOT change event names or
     4→ * payload shapes without updating BOTH sides.
     5→ *
     6→ * Model (v6 — pure private messenger, like WhatsApp/Telegram):
     7→ *   Every person who opens the app logs in with a name and gets a
     8→ *   private 1-on-1 chat with the Admin account (the app owner), just
     9→ *   like messaging any contact.
    10→ *   - A user NEVER sees other users, their presence, or their messages
    11→ *     (enforced server-side via participant checks).
    12→ *   - The Admin (owner) sees ALL conversations in one list, like
    13→ *     WhatsApp Web.
    14→ *   - Messages: text | image | voice | file | system (+ replies, edit,
    15→ *     delete-for-everyone, emoji reactions, live ✓✓ read receipts, pinned
    16→ *     messages, archive, voice-note transcription, on-demand translate,
    17→ *     Web Push notifications, document/video/audio file sharing).
    18→ *   - v8 (server-lightening): ALL media (photos & voice notes included)
    19→ *     lives on disk under db/media/ and travels as /api/media/<name> URLs
    20→ *     (legacy in-band data URLs still render but are no longer produced).
    21→ *     Photos/videos get tiny client-side thumbnails (`thumbUrl`); history is
    22→ *     paginated (50/page, `messages:older` loads more); media ages out after
    23→ *     MEDIA_RETENTION_DAYS (server sweeps → `mediaExpiredAt` tombstone);
    24→ *     per-account rate limits + storage quota guard the socket.
    25→ *   - Files are uploaded out-of-band via the Next.js route POST /api/upload
    26→ *     (stored under db/media/, SHA-256 deduplicated) and the message carries
    27→ *     the public URL /api/media/<name> plus fileName/fileSize/mimeType.
    28→ *     GET /api/media/<name> streams bytes with immutable caching, ETag/304
    29→ *     and HTTP Range support (video seeking without full re-download).
    30→ *
    31→ * NO customer-service tooling lives here anymore: no operating hours,
    32→ * no quick-reply templates, no AI auto-reply/summary/suggestions, no
    33→ * SLA alerts, no chatbot menu, no pre-chat form, no star ratings, no
    34→ * broadcast, no CRM labels/notes, no stats, no CSV/PDF export.
    35→ */
    36→
