    16→Stage Summary:
    17→- Protocol (client→server, ack via callback):
    18→  user:join {sessionId?, name} → {ok, session:{id,name}, messages} | {ok:false,error}
    19→  user:message {sessionId, content} → {ok, message} | err
    20→  user:typing {sessionId, isTyping} (no ack)
    21→  admin:auth {password} → {ok, sessions} | err
    22→  admin:sessions (no payload) → {ok, sessions}
    23→  admin:history {sessionId} → {ok, messages} (also marks read)
    24→  admin:message {sessionId, content} → {ok, message} | err
    25→  admin:read {sessionId} (no ack)
    26→  admin:typing {sessionId, isTyping} (no ack)
    27→- Server→client: chat:message (ChatMessage, to session room + admins room), sessions:update (SessionOverview[], to admins), user:typing {sessionId,isTyping}, admin:typing {isTyping}
    28→- Rooms: `session:${sessionId}` per customer, `admins` for all authenticated admin sockets
    29→- Storage: bun:sqlite at mini-services/chat-service/chat.db (sessions, messages, admin_reads tables)
    30→- Admin password: ADMIN_PASSWORD env or default "admin123"
    31→- Socket connection pattern (blessed by scaffold example): io('/?XTransformPort=3003', {transports:['websocket','polling'], forceNew:true, reconnection:true, timeout:10000})
    32→- Constraints: single route (src/app/page.tsx), no server actions, Indonesian UI, emerald theme (no blue/indigo), sticky footer, responsive
